Privacy Policy

Auto YouTube AI Employee · Last updated: 8 November 2026

This application ("Auto YouTube AI Employee") is a personal automation tool operated by Ramiz (ramizraj629@gmail.com). It generates short educational videos and small web tools and publishes them to the operator's own YouTube channel. This policy explains what data the application accesses and how it is used.

1. Who this applies to

This is a single-user, personal tool. It is used only by the operator to manage their own YouTube channel. It does not offer accounts to the public and does not collect data from viewers or third parties.

2. Google user data accessed

With the operator's explicit consent, the application requests the following Google OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — used solely to upload videos that the application itself generates to the operator's own YouTube channel.

The application does not read, modify, or delete existing videos, comments, playlists, channel settings, or any other YouTube data. It only performs uploads.

3. How the data is used

  • An OAuth refresh token is stored as a private repository secret and is used only to authenticate upload requests to the YouTube Data API.
  • Video titles, descriptions, and tags are generated automatically and attached to the uploaded video.
  • No Google user data is sold, shared, transferred to advertisers, or used for any purpose other than uploading the operator's own generated videos.

4. Data storage and retention

Credentials are stored encrypted as GitHub Actions secrets in a private repository. Generated video files are retained temporarily as build artifacts (up to 7 days) and then discarded. The application does not maintain a database of personal information.

5. Third-party services

The application uses the YouTube Data API (Google) to upload videos and the Gemini API (Google) to generate text. Use of these services is subject to Google's own terms and privacy policy. Text to speech is performed using open-source libraries.

6. Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

The operator may revoke the application's access at any time from their Google Account permissions page.

8. Contact

For any privacy questions, contact ramizraj629@gmail.com.
